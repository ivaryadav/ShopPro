# routes/licenses/

**Historical note (corrected during the RC1 repository audit)**: this README's original "Populated starting Phase 4 (SaaS Licensing & Subscriptions)" referred to an earlier, superseded phase-numbering scheme. The actual Phase 4 in this reconstruction (`docs/architecture/Phase4Review.md`) was Operations Domain Implementation, not Licensing — Licensing has not been assigned to any phase yet and remains entirely unported to `server/src/` as of Phase 6 (`docs/architecture/ParityValidation.md`).

Reserved for: registration, email verification, admin approval, subscription plans, renewal, and the license status-transition lifecycle (`PENDING_APPROVAL → ACTIVE → READ_ONLY → SUSPENDED → ARCHIVED`) — ported from `server/local.js`'s `tenant_licenses`/`license_history`/`subscription_plans` logic, the single most heavily audited subsystem in this project (see `docs/independent-audit/`), whenever a future phase takes this on. That phase's ported version must pass an equivalent regression suite before it can be considered complete, per ADR-0001.
